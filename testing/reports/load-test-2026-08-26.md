## Bottlenecks addressed in code

1. **Catalog search `LOWER(name) LIKE %q%`** — Criteria query does not use `search_vector`.
   - **Fix:** Flyway **V21** `pg_trgm` GIN indexes on `lower(name)` and `lower(brand)`.
2. **Hikari pool default 10** — concurrent browse + checkout waits on connections.
   - **Fix:** `spring.datasource.hikari.maximum-pool-size=25`.
3. **SQL debug logging** — `show-sql` and Hibernate bind traces dominate CPU under load.
   - **Fix:** `show-sql=false`, Hibernate SQL `WARN`, app log `INFO`.
4. **Checkout row locks** — `SELECT … FOR UPDATE` on stock; S2 will fail after seed stock is gone. Expected, not a browse-SLA miss.
5. **Images** — listing/cart use **thumb** variants so load paths do not pull full-size files.

## If a run breaks the SLA
